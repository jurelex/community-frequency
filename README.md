# Community Frequency

## Resilient communications for places where conventional connectivity does not reach

Community Frequency is an exploratory project focused on community-owned, low-power communication systems and their role within resilient communications infrastructure.

This repository is the **public project record**. It documents research, experiments, field observations, decisions, failures, lessons learned, and the development of the project over time.

This is not a finished solution. The project is deliberately evidence-driven: **listen, measure, learn, and build**.

## Documentation model

The public repository is a curated publication layer derived from a private Master Vault. Sensitive operational, personal, security, and private organizational information is intentionally excluded.

## Current phase

**Phase 0 — Discovery & Feasibility**

The immediate focus is research and field assessment, including preparation for the planned Peru 2026 feasibility mission.

## Technology neutrality

Community Frequency does not depend on one specific mesh technology. Meshtastic and MeshCore are being evaluated as parallel technology tracks alongside existing communications infrastructure such as HF, satellite, cellular, and Internet connectivity.

## Why publish the work?

The project is being developed openly so supporters and collaborators can see what is actually being tested, what works, what does not, and how conclusions change as evidence accumulates.
