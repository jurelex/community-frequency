# 2026-09-02 — Meshtastic Fixed-to-Mobile Test

## English
One direct mobile-to-fixed message was observed at approximately RSSI -44 dBm, SNR +11.25 dB, 0 hops.

Examples of relayed observations included approximately:
- -100 dBm / +4.5 dB / 2 hops
- -121 dBm / -10.75 dB / 1 hop
- -102 dBm / +4.25 dB / 2 hops
- -100 dBm / +7.25 dB / 1 hop

These observations demonstrate direct and relayed communication under the tested conditions. They do not establish a general coverage radius. A relayed packet's RSSI/SNR at the receiving fixed node is not an end-to-end measurement of the mobile-to-destination RF path.

The test was not a statistically controlled coverage study.

Entre las observaciones retransmitidas:
