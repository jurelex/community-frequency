The Project

Start with the problem. Then test the tools.

Independent exploration, research, and feasibility work.

Community Frequency is an independent project focused on resilient communications for places where conventional connectivity does not reliably reach. The project is currently in Phase 0 — Discovery & Feasibility.

The central question:
How can communities maintain basic communications when cellular or Internet connectivity does not reach them or is not enough?

Technology is the tool

Community Frequency is technology-neutral. Meshtastic, MeshCore, HF radio, satellite, cellular, and Internet connectivity may each have a role, but none is assumed to be the answer by itself.

The project is interested in how different layers could complement one another — from local low-power communications and elevated repeaters to longer-distance or connected systems.

How we work

Listen

Understand local needs, existing communications, constraints, and priorities before designing around a technical solution.

Measure

Use field tests to observe delivery, paths, signal conditions, mobility, power, and operational behavior.

Learn

Separate measured observations from interpretations and preserve uncertainty instead of hiding it.

Build only when the evidence supports it

A successful feasibility effort does not have to end with a deployment. The responsible conclusion may be that a particular approach works in a defined environment, needs more research, requires additional infrastructure, is unsuitable, or should be replaced by a different approach.

A finding that a technology does not work for a particular environment is still useful evidence.

Documentation matters

The public GitHub repository records the project's research, experiments, findings, funding transparency, and history. The website provides the public-facing explanation; the repository provides the deeper working record.
