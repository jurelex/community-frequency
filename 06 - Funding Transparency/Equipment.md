# Equipment / Equipos

## English

The project uses commercially available low-power radio hardware for controlled experimentation.

Current field research includes Heltec V4 hardware used in parallel Meshtastic and MeshCore experiments, along with supporting equipment for mobile testing, antennas, power, and documentation.

The project may also evaluate donated or surplus equipment when it is relevant to the feasibility work.

Specific device identifiers, private configurations, credentials, security keys, and sensitive location information are intentionally omitted from this public record.

Equipment donations should be discussed before shipment so usefulness, compatibility, safety, and suitability for the project can be evaluated.

## Español

El proyecto utiliza hardware de radio de bajo consumo disponible comercialmente para realizar experimentos controlados.

La investigación de campo actual incluye hardware Heltec V4 utilizado en experimentos paralelos con Meshtastic y MeshCore, junto con equipos de apoyo para pruebas móviles, antenas, energía y documentación.

El proyecto también puede evaluar equipos donados o excedentes cuando sean relevantes para el trabajo de factibilidad.

Los identificadores específicos de dispositivos, configuraciones privadas, credenciales, claves de seguridad y datos de ubicación sensibles se omiten deliberadamente de este registro público.

Las donaciones de equipos deben consultarse antes de enviarse para poder evaluar su utilidad, compatibilidad, seguridad y adecuación para el proyecto.
