# Project Transparency / Transparencia del Proyecto

## English

Community Frequency is being developed in the open.

This public repository is a curated publication layer derived from a private Master Vault. It is intended to provide a contemporaneous record of research, field work, experiments, decisions, failures, and lessons learned.

The project is currently an independently organized exploratory project and is not a 501(c)(3) nonprofit organization.

Project-specific fundraising supports assessment-related equipment, testing, coordination, and other project expenses. Family vacation and normal personal travel expenses are separate from project fundraising.

Some information is intentionally excluded for security, privacy, and community-safety reasons. This includes credentials, security keys, private configurations, personal information, and sensitive location information where disclosure could create risk.

### Publication principle

Public documentation should describe what was actually observed and preserve uncertainty where conclusions are preliminary.

The goal is accountability and evidence, not a polished success story.

## Español

Community Frequency se está desarrollando de manera abierta.

Este repositorio público es una capa de publicación seleccionada a partir de un Master Vault privado. Su propósito es mantener un registro contemporáneo de la investigación, el trabajo de campo, los experimentos, las decisiones, las fallas y los aprendizajes.

Actualmente el proyecto es una iniciativa exploratoria organizada de manera independiente y no es una organización sin fines de lucro 501(c)(3).

Los fondos recaudados específicamente para el proyecto apoyan equipos de evaluación, pruebas, coordinación y otros gastos relacionados con el proyecto. Los gastos familiares de vacaciones y los gastos normales de viaje personal son independientes de la recaudación del proyecto.

Cierta información se excluye deliberadamente por razones de seguridad, privacidad y protección comunitaria. Esto incluye credenciales, claves de seguridad, configuraciones privadas, información personal y datos de ubicación sensibles cuando su divulgación pueda generar riesgos.

### Principio de publicación

La documentación pública debe describir lo que realmente se observó y conservar la incertidumbre cuando las conclusiones sean preliminares.

El objetivo es la transparencia y la evidencia, no una historia de éxito cuidadosamente pulida.
