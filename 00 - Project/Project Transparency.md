# Project Transparency

Community Frequency is being developed in the open.

This repository is intended to provide a contemporaneous record of the project's research, field work, experiments, decisions, failures, and lessons learned.

The project is currently an independently organized exploratory project and is not yet a 501(c)(3) nonprofit organization.

Project-specific fundraising supports assessment-related equipment, testing, travel, coordination, and other project expenses.

Some information is intentionally excluded for security, privacy, and community-safety reasons. The private Master Vault contains the complete working record.

## Publication principle

Public documentation should describe what was actually observed and should preserve uncertainty where conclusions are preliminary.

The goal is accountability, not a polished success story.
