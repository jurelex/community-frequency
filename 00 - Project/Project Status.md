# Project Status

**Last updated:** 2026-09-06

## Current phase

**Phase 0 — Discovery & Feasibility**

The project is documenting and testing resilient low-power communications approaches before proposing a deployment model.

## Active work

- Arizona field experimentation
- Parallel Meshtastic and MeshCore testing
- Network and RF observations
- Logging and data collection
- Peru feasibility planning
- Regulatory and operational research
- Partner/community research

## Near-term milestone

Planned Peru assessment beginning September 27, 2026.

The mission is intended to learn about existing communications systems, constraints, community needs, regulatory considerations, and appropriate technology choices rather than arrive with a predetermined deployment solution.
