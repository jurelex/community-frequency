# Bilingual Documentation Convention / Convención de Documentación Bilingüe

## Purpose / Propósito
Community Frequency will use English and Spanish for major public-facing documentation so supporters, collaborators, and potential partners in Peru can access the project record directly.

## Publication rule / Regla de publicación
Major public documents should have English and Spanish versions when relevant to project purpose, public funding, Peru assessment, major findings, methodology, or field experiments that materially support public understanding.

Highly specialized technical notes do not need immediate Spanish translation.

## Language quality / Calidad lingüística
Spanish versions should be localized and readable for a Latin American/Peruvian audience. They should not blindly translate technical terminology.

Keep widely recognized technical terms where useful: Meshtastic, MeshCore, RSSI, SNR, hop, repeater, Flood, Direct, ACK, GPS.

## Evidence integrity / Integridad de la evidencia
English and Spanish versions must communicate the same evidence level. Translation must not strengthen a claim, remove a limitation, turn a hypothesis into a conclusion, or turn an assessment into a deployment commitment.

## Public/private boundary / Límite público/privado
Both language versions must follow the same security and privacy rules. Sensitive operational information is not translated and published merely because a Spanish version exists.
